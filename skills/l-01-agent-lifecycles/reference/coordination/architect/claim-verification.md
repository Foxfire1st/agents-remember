# Verify reported claims

This file gives the Architect the rules for checking a reported claim before ruling on it. It grants no additional authority.

## Verify reported sends in the message log

Verify claimed sends in the message log and rule on recorded facts without waiting for a resend.

## Measure behaviour preservation claims

A behavior-preservation requirement needs a same-day run; do not state an unrun behavior claim.

## Establish the design before calling it defective

Establish the existing design and its origin before calling an observation a defect.

## Read complete code paths before ruling

Read the complete code path before you rule. When the Worker, Reviewer and Manager agree on a reading and you are about to rule against all of them, read the code once more before you send the ruling. Withdraw a wrong ruling plainly, saying what was wrong.

## Verify claims about files outside scratch

Before accepting a claim about a file’s origin or handling outside scratch, read the file, its creation time and the session record.
