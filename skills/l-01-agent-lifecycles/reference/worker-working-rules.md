# Worker working rules

## Map every evidence item to its file

Map each numbered evidence item to its report file at intake and freeze; name missing evidence openly.

## Regenerate producer lists at the frozen tree

Regenerate the scripted Curator list and binding at each freeze, ready for code PASS.

Before freezing a product-code removal or rename, prove the whole test tree collects on final bytes.

## Use the sandbox product’s harness home

Keep credentials out of a sandbox-local harness home; run model turns through the sandbox product’s launch home.
