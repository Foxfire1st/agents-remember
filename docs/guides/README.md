# Guides

Each guide tells how to do one thing with an installed Agents Remember.
[Getting started](../getting-started.md) describes the installation itself.

Set up the memory of a repository:

- [Onboard An Existing Repository](onboard-existing-repo.md) creates the memory repository of a
  code repository that has none.
- [Use The Memory Repository](use-external-memory.md) shows where the memory lies and how a
  closeout keeps code and memory in step.
- [Adopt Existing Memory](adopt-existing-memory.md) makes the content of a memory
  repository the first [baseline](../concepts.md#baseline).
- [The Cost Of A Repository's First Memory](cost-aware-bootstrap.md) gives advice on the cost of
  the first work on a repository.

Keep the memory current:

- [Refresh Stale Cards](refresh-stale-onboarding.md) finds stale cards and refreshes them.
- [Carry Memory From a Branch](carryover-from-branch.md) brings memory from another branch into
  the memory of a task.

Review a change:

- [The review page and the explainer](review-page-and-explainer.md) describes the review page of
  a task and its [explainer](../concepts.md#explainer), the agent that answers your requests on
  that page.
