# Reference

Use these pages to look up an exact name: a tool and its arguments, a settings key, a file or a
folder, a field of a record.

Tools:

- [MCP Tool Reference](mcp-tools.md) has one row for every tool of the tool server.
- [Tool details](../tool-details.md) holds the longer explanation of each tool whose short
  description points to it.

Settings:

- [Settings Reference](settings-json.md) describes the four settings files.
- [Harnesses and role settings](harnesses.md) describes how the start of a role agent takes its
  harness, its model and its effort.
- [Path Rules](path-rules.md) describes which files of a code repository are eligible for cards.

Files and folders:

- [Runtime Layout](runtime-layout.md) lists what an installation puts on disk.
- [Product Context Resolution](resolver-c08.md) describes how a code repository resolves to its
  memory repository, its settings and its task folder.

Memory:

- [Knowledge System](knowledge-system.md) describes the cards, the knowledge records and the
  knowledge gate.
- [Memory Quality Control](drift-c02.md) describes the checks on the cards: the
  [drift check](../concepts.md#drift-check) of `context_packet` and the tool `memory_quality_check`.

Tasks and roles:

- [Worktrees And Closeout](worktrees-c09.md) describes the worktree tools, the closeout and the
  landing.
- [Execution-topology authoring](execution-topology.md) describes the
  fields `executionNature` and `executionGraph` and the operation that writes the graph of a
  sprint.
- [Role capsules, handovers and messages](role-capsules.md) describes the
  [role capsule](../concepts.md#role-capsule), the instruction text that a role agent receives at
  its start.
- [Skills Reference](skills.md) describes the [skills](../concepts.md#skill) that the tool server
  serves.

Certification:

- [Repository Certification Profiles](repository-certification-profile.md) says when a
  [certification](../concepts.md#certification) runs and describes the format of a repository
  certification profile.
