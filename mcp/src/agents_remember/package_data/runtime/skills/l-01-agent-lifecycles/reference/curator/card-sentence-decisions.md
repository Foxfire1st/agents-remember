# Decide card sentences before editing

Curators read this topic before editing a card or its paired notes. It defines sentence-by-sentence decisions, source checks and repairs while preserving present truth about retired things.

Cards say what is true now. Decide each sentence of every card and its paired notes, including reference captions, one by one, whatever its tense or location, dated sections included. Edit individual sentences; never replace a section or regenerate a card wholesale.

When a sentence is true now, keep its wording, also when it states something true about a retired thing. Before keeping a sentence, verify it in the supplied source. Before narrowing or dropping one, search the supplied source and memory for what supports it. A sentence about what happens is true only if that code runs today; code that exists but never runs does not make it true.

A sentence that something is written, started, sent or served somewhere says that it happens, even when it only names the place; check it where that action is started, not only where its path or setting is defined.

**Write each decision down before you edit.** For every card you touch, list each of its sentences and paired-note captions with keep, reword or drop and the source line that decides it. Edit from that list, and put it in your report. A reworded sentence is a new claim: verify it in the source like any other, and name no receiver, helper or step that the source does not have.

Repair or withdraw every false claim in every current carrier found by a bounded search: the card body, paired notes and sibling cards. Repair the class, not just one example.

Remove past accounts, including dated change notes, “former … was removed” and “The fix: …”, from the card and name them in that card's history row, written after the card's last edit. A dated note can still hold sentences that are true now: keep those in the card without the date or the change story, and remove only the account of the change.
