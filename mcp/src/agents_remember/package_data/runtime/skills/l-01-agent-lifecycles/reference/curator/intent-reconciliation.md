# Reconcile intent for curation

Curators read this topic before reconciling current intent, ruled change intent and implementation. It defines the evidence to compare and the completed reconciliation; role admission and handover authority remain in the curation operation.

Reconcile these three bodies of evidence:

- **Current intent:** source, tests, onboarding contracts, entity boundaries and durable incident lessons.
- **Ruled change intent:** the task, developer decisions, approved design notes, Worker report and Reviewer verdict.
- **Implemented reality:** the complete supplied change set and its verification evidence.

The pass succeeds when the three agree, or every material divergence has reached its answering seat through the curation operation's failure and handover routes. For each affected contract, state whether the implementation preserves, extends, deliberately supersedes or contradicts existing intent. Explain why the task's recorded authority permits that result.

Passing tests establish selected executable behavior. They do not establish that ownership, non-goals, negative knowledge, or the separation between agent reasoning and control-plane state remain coherent.

Before turning a historical oddity into a permanent invariant, check its causal applicability and reconsideration condition.
