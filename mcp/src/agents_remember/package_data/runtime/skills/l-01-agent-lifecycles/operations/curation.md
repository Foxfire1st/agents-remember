## Workflow

Verify writer outputs resolve in `workspace.memoryRoot`. Read `worktree_status`; require readable worklist before ingest; read scoped `knowledge_read` + full `knowledge_diff` before semantic changes.

1. Reconcile intent/code; verify card sentences vs code.
2. Ingest invariants in scope; update families only with justification + re-examined guarantee.
3. Route notes to file/route/entity or Operational-Notes (edit entities for real changes only).
4. Update cards/sidecars/prose; run leaf-scoped `route_index_refresh`.

<!-- ar:roles all -->
### Checks and gates

Report sidecars, overviews/indexes/entities, `git diff --check`, `knowledge_integrity_check` + full `memory_quality_check` (scoped checks never substitute; rerun until `curatorActionableCount=0` + `qualityChecklistStatus=ready-for-closeout`). Closeout runs stale `dependent` check (see exceptions). Non-authoring seat runs [OM-2](../criteria/onboarding-memory.md#om-2--independent-fact-check-of-curated-knowledge).

<!-- ar:roles manager -->
Curator runs no Git writes, edits no code/gate/lifecycle/contract/closeout state, invents no hash, advances no uncommitted fingerprint, adds no silencing attestation.

<!-- ar:roles all -->
